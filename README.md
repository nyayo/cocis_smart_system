# CoCIS Smart Control & Monitoring System (ESP32 + ESP-IDF + Wokwi)

3-terminal system: master entrance terminal (RFID x2, servos, RTC, SD card,
LCD, buzzer, ESP-NOW receiver, serial menu) + 2 room terminals (PIR motion,
automatic lighting, ESP-NOW senders).

## Project layout

    cocis_smart_system/
    ├── platformio.ini        # 4 environments: standalone, entrance, room1, room2
    ├── diagram.json          # Wokwi circuit (standalone build)
    ├── wokwi.toml
    ├── sdcard/               # SD card contents, kept between simulation runs
    └── src/
        ├── main.c            # common entry -> entrance or room firmware
        ├── common.h          # pins, ESP-NOW message format, constants
        ├── entrance_main.c   # MASTER terminal firmware
        ├── room_main.c       # ROOM terminal firmware
        ├── rc522.c/.h        # MFRC522 SPI driver (UID read)
        ├── ds3231.c/.h       # RTC driver (falls back to the software clock)
        └── lcd1602_i2c.c/.h  # LCD via PCF8574 backpack

`sdkconfig.*` files are generated by PlatformIO on the first build and are
git-ignored.

## Build & run (VS Code + PlatformIO + Wokwi extension)

    pio run                          # "standalone": the whole system on one ESP32
    pio run -e entrance -e room1 -e room2   # 3-board build for real hardware

Then start the Wokwi simulator (Wokwi: Start Simulator).

## First-time setup in Wokwi

1. Set the RTC from the serial monitor:  `settime 14 30 0` and `setdate 22 10 26`
2. Default schedule is 06:30-21:00. Change it with:
   `login admin123`, `setopen 07:00`, `setclose 22:00`
3. Wokwi MFRC522 preset cards: Blue 01020304, Green 11223344, Red AABBCCDD are
   registered by default. Register more with `addtag <UID> <name>`; use
   `scan` to read the UID of a card.
4. Trigger the PIR sensors in Wokwi to simulate motion.

## Synchronization design (for the report)

- The entrance terminal is the ONLY SD-card writer -> no file-level races.
- FreeRTOS mutexes: `state_lock` (occupancy, tag table, room states, alarm),
  `sd_lock` (file access), `lcd_lock` (display), `door_lock` (one access
  decision / door movement / alarm beep at a time). Lock order is always
  state_lock -> sd_lock.
- Anti-tailgating: a tag already inside is denied entry; an exit needs a
  matching entry record; occupancy can never go negative.
- Rooms -> entrance: FreeRTOS queue (standalone) or ESP-NOW (distributed), with
  magic/type validation and a 10 s heartbeat, so lost packets do not
  desynchronize the master.

## Notes

- SD card is on HSPI (SCK=14, MISO=12, MOSI=13, CS=5); the two RC522s share
  VSPI (18/19/23, CS=15/2). GPIO12 is a strapping pin - fine in Wokwi; move
  MISO to another pin on real hardware.
- ESP-NOW works between the 3 boards in one Wokwi project without a router.
